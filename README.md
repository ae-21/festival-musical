# 🎸 Simulador de Festival Musical en Python

Simulador de un festival musical desarrollado como actividad académica para demostrar el dominio de los pilares de la Programación Orientada a Objetos (POO): **Herencia**, **Polimorfismo** y **Redefinición de métodos**.

## 📂 Estructura del Proyecto

festival_musical/
│
├── clases/
│   └── artistas.py    # Contiene la clase base Artista, clases derivadas y validaciones.
├── main.py           # Programa principal con menú interactivo y ejecución polimórfica.
└── README.md         # Documentación del proyecto.

## 🚀 Requisitos e Instalación

- Tener instalado **Python 3.x** en tu computadora.
- Clonar o descargar este repositorio en tu máquina local.

## ▶️ ¿Cómo ejecutar el programa?

1. Abre una terminal en la carpeta raíz del proyecto (`festival_musical`).
2. Ejecuta el archivo principal con el siguiente comando:
